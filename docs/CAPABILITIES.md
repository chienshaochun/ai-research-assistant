# 功能盤點與精簡候選

最後更新：2026-10-06（Asia/Taipei）

這份清單是精簡 UI 前的基準。現階段不刪除功能或資料；先區分核心能力、進階工具與內部診斷，再由使用者決定哪些項目移到「進階」或完全移除。

## 必須保留的核心

- 官方登入與方案授權邊界。
- 有界搜尋／閱讀、SSRF 防護、取消與錯誤上限。
- 保存實際證據、引用 ID 驗證與來源主張／助理分析分離。
- 長期偏好、當次設定、對話指向與歷史報告的分離。
- 主動監測、去重、回饋、每日模型用量硬上限與資料備份。

## 可先移到「進階／診斷」的 UI

1. 階段 A 的模型文字驗證與 Web Search 能力探測：首次設定後收進「連線診斷」。
2. citation support 工作表：保留能力，但從主流程移到「評估工具」。
3. 失敗嘗試來源明細與背景 run history：預設折疊，只在除錯時展開。
4. 數值稽核、來源 hash、擷取證據全文：報告只顯示摘要，完整資訊放「證據細節」。
5. Markdown／評估工作表／可攜備份：集中到單一「匯出與資料」選單。
6. 官方 Web Search 的顯式 provider 指令：保留自然語言能力，設定介面只在進階模式顯示。

## 暫不建議刪除

- 不刪除 SQLite 失敗紀錄；它是定位搜尋、日期與引用問題的證據。
- 不刪除來源摘要與內容 hash；報告可追溯性依賴它們。
- 不刪除人工 citation 評估；可隱藏但它是建立品質 baseline 的入口。
- 不把背景摘要改成每次搜尋都呼叫模型；每日一次上限是控制方案用量的核心保護。

## 尚未完成或受外部條件限制

- 官方 Web Search 完整研究路徑仍缺一次使用者明確觸發的真實 E2E。
- Windows toast 的實際視覺呈現仍需桌面 demo。
- NSIS Setup EXE 與 ZIP 便攜版已產生；兩者均未做可信程式碼簽章，其他電腦可能顯示 SmartScreen 或組織政策警告。
- win-unpacked 的 app.asar 已以 Electron runtime smoke test 通過；安裝器本身尚未執行安裝／解除安裝 E2E。
- 官方 feeds 是有限可信來源集合，不等於完整網路搜尋；feed endpoint 失效時會降級使用其他成功 provider。
